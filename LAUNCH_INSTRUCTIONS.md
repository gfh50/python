# 🚀 Инструкция по запуску системы опросов

## Полное приложение готово к запуску!

Создана полная система опросов с фронтендом на React и примером бэкенда на Python.

---

## 📋 Что создано

### ✅ Frontend (React)
- **CreatePoll.js** - форма создания опроса с таймером и генерацией ссылок
- **PollView.js** - просмотр опроса с проверкой времени и таймером обратного отсчета
- **PollList.js** - список всех опросов с управлением
- **App.js** - роутинг и навигация
- Полная валидация форм с Formik + Yup
- Адаптивный дизайн Material-UI

### ✅ Backend (Python) - пример структуры
- **models.py** - модели SQLAlchemy для БД
- **crud_poll.py** - CRUD операции с поддержкой времени
- **requirements.txt** - зависимости для бэкенда

## 🔧 Полная установка с бэкендом

### Фронтенд

1. **Установка зависимостей**
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки**
   ```bash
   npm start
   ```

### Бэкенд (Python/FastAPI)

1. **Создание виртуального окружения**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # или
   venv\Scripts\activate     # Windows
   ```

2. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройка базы данных**
   ```bash
   # Создать файл .env
   echo "DATABASE_URL=sqlite:///./polls.db" > .env
   ```

4. **Запуск сервера**
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

## 🎯 Основные возможности

### ✨ Создание опросов
- Название и описание
- Временные рамки (начало/окончание)
- Разные типы вопросов:
  - **Один вариант** (radio buttons)
  - **Несколько вариантов** (checkboxes)  
  - **Текстовый ответ** (textarea)
- Автоматическая генерация ссылок
- Копирование ссылки в буфер обмена

### ⏰ Временное управление
- Таймер обратного отсчета
- Блокировка доступа вне времени
- Уведомления о статусе опроса
- Проверка времени в реальном времени

### 📊 Управление опросами
- Просмотр всех созданных опросов
- Статусы: "Не начался", "Активен", "Завершен"
- Удаление опросов
- Быстрое копирование ссылок

## 🔗 API интеграция

Для подключения к реальному бэкенду измените:

### В CreatePoll.js (строка ~61):
```javascript
// Замените localStorage на:
const response = await axios.post('http://localhost:8000/api/polls', pollData);
```

### В PollView.js (строка ~32):
```javascript
// Замените localStorage на:
const response = await axios.get(`http://localhost:8000/api/polls/${id}`);
```
